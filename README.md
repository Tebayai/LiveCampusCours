# LiveCampus — Supports de cours

Ce dépôt est mon support de cours pour ma **3ᵉ année d'alternance** avec l'école **LiveCampus** (2026-2027).

J'y range tous les cours, exercices, challenges et projets réalisés pendant l'année, pour garder une trace de ma progression et pouvoir revenir sur une notion plus tard.

## Organisation

Chaque matière a son propre dossier à la racine. Dedans, un sous-dossier par thème, puis un dossier par exercice.

```
LiveCampusCours/
└── htmlCssJs/              HTML, CSS et JavaScript
    ├── animation/          Transitions et animations CSS
    ├── integration/        Intégrations de maquettes (desktop + mobile)
    ├── challenge/          Challenges d'intégration
    └── JS/
        ├── htmlJS/         Manipulation du DOM
        ├── API/            Appels d'API avec fetch (dont le challenge CoinBase)
        ├── challenge/      Challenges JavaScript
        └── bonus/          Exercices bonus
```

Les prochaines matières (par exemple PHP / Symfony) seront ajoutées dans de nouveaux dossiers à la racine au fil de l'année.

## Contenu d'un exercice

Un exercice contient en général :

- `index.html`, `style.css` et/ou `app.js` : le code de l'exercice
- `design/` : les maquettes à reproduire (pour les intégrations)
- `images/` : les ressources graphiques
